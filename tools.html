Common

常用工具

日常处理文件用。全部在浏览器里跑，文件不上传服务器。

Tool 01 图片处理 把图片压到指定分辨率以内。等比缩放，只缩小不放大。默认上限 1000 × 4000。 打开工具 → Tool 02 视频处理 读取视频的时长、分辨率与编码，按投稿规范转换，也可自定义比例、分辨率与编码。 打开工具 → Tool 03 格式转换 从视频或音频里抽出音轨转成 WAV，JSON 与 CSV 互转，文本 Base64 编解码。 打开工具 →
