工具箱

投稿用的工具箱

三个模块，各管一件事。图片和视频都在你的浏览器里处理， 文件不上传任何服务器，关掉页面就什么都不剩。

Tool 01 图片处理 把图片压到指定分辨率以内，等比缩放不变形。投稿长图默认压到 1000×4000 以内。 打开工具 → Tool 02 视频处理 诊断时长／分辨率／编码，按投稿规范一键转换，也能自定义比例、分辨率与编码（H.264）。 打开工具 → Tool 03 · 组员作品 matoga 材质贴图对比 芝世 开发的桌面应用：两个文件夹的材质贴图差异对比 + 3D PBR 实时预览。Windows / macOS / Linux。 了解与下载 →
🛈
前两个是网页工具，打开就能用；第三个是开发组成员做的桌面软件，需要下载安装。 有想加的工具可以到 联系我们 提。
