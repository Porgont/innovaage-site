工具箱

Tool 01 图片处理 把图片压到指定分辨率以内。等比缩放，只缩小不放大。默认上限 1000 × 4000。 打开工具 → Tool 02 视频处理 读取视频的时长、分辨率与编码，按投稿规范转换，也可自定义比例、分辨率与编码。 打开工具 → Tool 03 格式转换 从视频或音频里抽出音轨转成 WAV，JSON 与 CSV 互转，文本 Base64 编解码。 打开工具 → Tool 04 · 组员作品 MCBE 打包器 安卓应用。专为 Minecraft 基岩版（Bedrock Edition）及网易版（NetEase）设计的综合性资源包（材质包）与模型打包工具。作者：小白。 了解与下载 →

About Us

我们是谁

我们已入驻网易我的世界，并在网易大神等平台注册有官方账号， 在我的世界中国版总下载量已超过五千万。 团队创始人为威廉，主打地图、皮肤等资源类型。

我们坚持开放的基本战略，愿意与团队及个人建立合作关系。 欢迎 MC 圈人士加入对外群学习探讨，携手一同成就梦想。

What We Do

我们做什么

主打地图与皮肤，同时覆盖材质、光影与 Addon

🗺️

地图 / 世界

冒险、解谜、跑酷、生存挑战、剧情向地图。包含关卡设计、地形塑造与玩法平衡。

🧑‍🎨

皮肤

角色皮肤绘制与成套皮肤包，风格统一，适配基岩版与中国版。

✨

光影 / Shader

画面调校与自研效果：光照、水面、体积雾、昼夜氛围，兼顾观感与帧率。

🧱

材质 / 资源包

方块、物品、界面、字体的重绘与风格统一。写实、卡通、像素复古都可以。

⚙️

Addon

基岩版 Addon：自定义实体、方块、物品、配方、成就与玩法机制。

🎬

美术 / 视频

封面、宣传图、logo、UI 与预告片剪辑。作品发布需要的视觉物料，我们自己做。
