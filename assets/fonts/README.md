# 站内字体：Noto Sans SC

页面正文和标题都用这一个字体。

| 项 | 内容 |
|---|---|
| 字体名 | Noto Sans SC |
| 版本 | 2.04 |
| 版权方 | Copyright © 2014-2021 Adobe（保留字体名 'Source'）；Copyright © 2021-2024 Google LLC |
| 许可证 | SIL Open Font License 1.1，全文见同目录 `OFL.txt` |
| 文件 | `noto-sans-sc.woff2` |
| 形态 | **可变字体**，`wght` 轴 100–900，一个文件覆盖全站所有字重 |

## 为什么用这个字体

OFL 1.1 明确允许**修改（含子集化）**和**随产品一起分发**，只要满足三条：

1. 不单独出售字体本身 —— 本站不卖字体
2. 分发时带上版权声明和许可证 —— 见同目录 `OFL.txt`
3. 修改版不得使用「保留字体名」—— 这份字体的保留名是 **Source**，我们没用到这个词，字体内部名保持 `Noto Sans SC` 未改

## 这个文件和原版有什么不同

原版是 16.9 MB 的完整字库（约 3.1 万个字形）。网站用不到那么多字，所以做了**子集化**：
只保留站内页面真正出现的字符（约 1100 个，其中汉字约 990 个），压成 woff2，约 314 KB。

- 字符表由 `tools/subset-font.mjs` 自动从全部 HTML 和 JS 里扫出来
- `name` 表完整保留，版权声明和字体名都还在，没有改名

## 什么时候要重新生成

页面文案里出现**以前没出现过的字**时，那几个字会回退成系统字体，肉眼能看出来粗细和字形不一致。

发了新公告、加了作品、改了固定文案之后，跑一次：

```bash
node tools/subset-font.mjs
```

依赖：本机装有 `python`（含 `fonttools`、`brotli`），并且系统里安装了 Noto Sans SC。
