# 图片目录 assets/img/

网站用到的图片都放这里。当前还没有图片，需要你提供。

## 建议的文件名与用途

| 文件名 | 用途 | 建议尺寸 |
|---|---|---|
| hero.jpg      | 首页顶部大图（地图全景 / 光影效果图） | 宽 1600~2400，横构图 |
| about.jpg     | 关于我们页的团队图或代表作 | 宽 1600 左右 |
| map-1.jpg     | 作品：地图 | 宽 1200 左右 |
| skin-1.jpg    | 作品：皮肤 | 正方形或竖构图 |
| shader-1.jpg  | 作品：光影 | 宽 1200 左右 |
| tex-1.jpg     | 作品：材质 | 宽 1200 左右 |
| addon-1.jpg   | 作品：Addon | 宽 1200 左右 |
| logo.png      | 工作室 logo（如果有） | 透明底 PNG，512×512 以上 |

文件名用英文小写加短横线，不要用中文名和空格，避免上线后链接出问题。

## 格式与体积

- 优先 **JPG**（游戏截图）或 **PNG**（需要透明底时）
- 单张控制在 **500KB 以内**最好，超过 1MB 我会帮你压
- 如果原图是 PNG 截图且体积很大，我会转成 JPG/WebP 再上线

## 怎么给我

直接把图片拖进对话窗口发给我，或者拷进这个文件夹后告诉我文件名。
