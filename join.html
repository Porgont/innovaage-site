Recruiting

我们在找谁

不要求全会，只要求你负责的那一块做得认真。可以同时报名多个方向。

🏗️ 建筑 / 地形

会做地形、建筑、室内或布景。能按参考图还原风格，也能自己定风格。

急缺

🔴 红石 / 命令方块

用红石或命令实现机关、关卡逻辑、演出效果。懂数据包机制优先。

⚙️ Addon / 数据包开发

会写基岩版 Addon（JS / JSON）或 Java 版数据包。能读文档、会调试。

急缺

✨ 光影 / Shader

懂 GLSL，能改光影包的光照、水面、雾效。有作品截图或视频最好。

🧱 材质 / 资源包

会画贴图，能保持一套风格统一。像素画、卡通、写实都可以。

🎨 美术 / 平面

做封面、宣传图、logo、UI。会排版，能用 PS / AI / Figma。

🎬 视频 / 剪辑

会录制游戏画面、剪辑预告片。懂节奏和音乐卡点更好。

📋 策划 / 测试 / 社区

写玩法设计、剧情文案；或者做测试、答疑、群管理。没经验也可以，愿意学就行。

报名问卷

带 * 的是必填。填写大约需要 2 分钟， 我们会逐份看，并在 3～7 天内通过你留的联系方式回复。

🛈
关于审核：我们不做付费入组，也不收任何费用；不要求你放弃其他团队。 报名通过后会先进「新成员」阶段，参与一个小任务，双方都觉得合适再转为正式成员。

合作 / 定制需求

需要定制地图、材质、光影、Addon，或做联动与宣传，请按下面的格式发邮件或加群私聊， 信息越全回复越快：

  1. 你们是谁（服务器 / UP 主 / 团队）
  2. 要做什么，参考案例或链接
  3. 目标平台与版本（Java / 基岩）
  4. 期望交付时间
  5. 是否有偿、预算范围
  6. 你的联系方式

反馈与报错

作品有问题需要反馈时，请说明：作品名称与版本、你的游戏版本、 问题发生的位置和步骤、截图或日志。这样我们能直接定位，不用来回问。

常见问题

  • 加入要交钱吗？不要。任何以工作室名义收费的都是假的。
  • 有年龄限制吗？没有硬性限制，能稳定沟通和交付就行。
  • 必须天天在线吗？不必。有事提前说，比突然消失重要。
  • 可以只做一个方向吗？可以，专精一个方向更受欢迎。
